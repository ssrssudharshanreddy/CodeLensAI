AI Model Provider

CodeLens AI runs on local Ollama by default. When publishing to Render, Hugging Face, or Cloud Run, switch to a hosted Cloud API (Gemini or Groq) with an API key.

Publishing to the Web

Deploy this application to free cloud hosts in 2 minutes:

Option 1: Render.com (Free Web Service)

1. Push this folder to GitHub.
2. In Render, select New Web Service.
3. Build Command: pip install -r requirements.txt
4. Start Command: uvicorn codelens.web.app:app --host 0.0.0.0 --port $PORT
5. Add environment variable: GEMINI_API_KEY

Option 2: Docker / Hugging Face Spaces

Build and run anywhere with the included Dockerfile:
docker build -t codelens-ai . && docker run -p 8000:8000 codelens-ai
